# Diffusion Policy 导轨代码整理

## 目标与范围

整理 `wys/tianji-pro6000` 的导轨数据读取、训练、评估、诊断和文档。保留图像增强、缩放裁剪及已有 checkpoint；上游其他任务、厂家 SDK 和独立插入实验不参与重构。

## 实施内容

1. 部署实现集中到 `diffusion_policy/real_world/tianji/`，配置、观测、环境、执行、推理、记录各自负责一项工作。业务包不依赖根目录脚本。
2. 提取模型无关的图像训练工作区；Transformer、UNet 各自创建优化器。训练循环拆为初始化、训练、评估、保存。
3. 实时追踪与离线分析、绘图分离；Runner 管理试验，记录器管理写盘。
4. Dataset 拆分配置与数据校验、来源划分、样本读取。训练和部署共享确定性预处理；增强只用于训练。
5. 统一 `python -m diffusion_policy.cli.tianji`，提供 `eval`、`replay`、`home`、`analyze`、`probe`。保留通用训练、评估入口、Hydra 配置名和 checkpoint 类路径。
6. 删除固定历史批次入口、专用 hooks 和测试；通用诊断显式接收输入、模型和输出路径。
7. README 约 80 行；导轨文档按训练、评估、开发组织，每篇原则上不超过 120 行。删除重复、过期材料及冗余压缩包，唯一有效结论汇总为简短摘要。

- 仅运行离线和 CPU 小规模验证，不运行长训练或真机运动。
