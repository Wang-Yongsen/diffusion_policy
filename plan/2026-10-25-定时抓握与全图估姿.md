# 定时抓握与全图估姿

当前流程替代此前的固定 ROI 连续检测闭合：进入 `receive.py` 控制流程后计时 5 秒，到时开始按默认手型闭合，抓前只有相机预览，不加载 CNOS 或 FoundationPose。视觉异常不会阻止定时闭合；G 可提前闭合。暂停后不继续抓握。`move_above.py` 的接料阶段同步使用定时闭合；已持轨入口不张手、不再次闭合。

闭合稳定后切换 RGB-D，CNOS 在全图 `[0,0,640,480]` 以 SAM 32×32 提示点生成候选 mask，DINOv2 与缓存 CAD 模板匹配；选中新 mask 后释放 CNOS，初始化 FoundationPose。普通接料入口单次估姿后释放模型、恢复彩色预览，窗口持续运行，右手保持、键盘点动保留。终端 T 重新执行全图 CNOS 与 FoundationPose 初始化，不重新抓握。

`grasp_delay_s: 5.0` 配置等待时间，`cnos_detection.full_image_points_per_side: 32` 配置全图提示点密度；旧固定 ROI 仅供 `view_detection.py` 诊断，不参与默认抓握或抓后估姿。窗口改为显示闭合倒计时，不显示固定区域框与连续检测计时。

全图推理耗时高于局部检索；存在多根相同导轨时按匹配分数选一个，不保证是握持中的目标。此前实机 RGB-D 取流超时仍待排查，本次不以模拟测试代替真机抓取或估姿验收。

验证：92 项相关测试通过（接料/相机阶段 43、可视化 9、目标上方 11、入口 7、预插入 22）。覆盖定时到达前不闭合、视觉启动失败仍按时闭合、抓前不加载模型、抓后全图范围与 32×32 提示点、使用新 mask、T 重识别不重复抓握，以及持续窗口与点动。语法检查和 `git diff --check` 通过，未执行真机动作。
