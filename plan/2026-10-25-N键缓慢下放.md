# N 键缓慢下放

用户选择按 N 开始下放，保持右手抓握，到装配目标后停止，不自动松手。

## 实现

- 共用 `receive.py`、`move_above.py`、`move_above_held.py` 的上方搬运流程。M 仍使用缓存均值、一个最终目标和 SDK 位置控制。
- 上方机械到位及视觉复核通过后，终端或图像窗口的 N 开始下放。提前、重复、暂停时的 N 只显示当前原因，不预存请求或恢复运动。点动后还需检查实测末端仍在上方目标。
- 复用冻结的 `T_F_O`，目标沿右 SDK 基座 -Y（整机向下）下降，固定目标横向坐标及朝向；50 mm 默认分成 10 个 5 mm 目标，最后一段恰好落在记录目标。
- 全部目标先通过 IK、关节/腕限位及每段关节变化不超过 0.05 rad 的检查。只在每段完成后发送下一个终点，不使用高频阻抗伺服轨迹。
- 右臂唯一控制线程将速度/加速度比例改为 1%，等待 SDK 配置回读，再调用位置运动；后续相同配置不重复下发配置。手保持线程独立运行。
- 每段同时要求 SDK 到位和实测法兰 1 mm / 1° 内稳定 0.2 秒。单段超时 20 秒；横向偏差超过 3 mm、姿态偏差超过 1° 或向下超出当前段目标 1 mm 时暂停。Q/空格/Ctrl+C/退出继续取消位置运动。
- 完成状态为 `placement_reached`，不再下降，不自动松手。记录 `lowering_plan.json` 和包含 FK 误差的结果；不把该状态写成已接触或已装配成功。

## 验证及限制

226 项相关回归测试通过（未运行独立打包搬迁测试）。复核后增加“持续按 N 不能跳过运动中的偏差检查”用例，并重新执行全部 45 项下放、上方搬运和位置运动相关测试，全部通过。语法与空白检查通过。

模拟设备验证 N 两个输入入口、M→上方→N→下放的完整流程、无自动下放、重复/提前 N、分段实测到位、暂停、偏移/超程/超时、慢速配置失败及抓握保持。另用旧实际运行记录进行官方 IK/FK 离线检查：10 段均可达，最大单段关节变化约 0.01861 rad，终点回算误差小于 0.001 mm / 0.001°；此数值只表示计算一致性。
