# FoundationPose 插入流程清理

## 已确认范围

基于 2026-10-26 最后版本的当前工作区继续整理，不回退或覆盖已有未提交工作。

唯一运动流程：接料抓握 → 初始估姿 → M 搬到目标上方 15 mm → 上方重新估姿并纠偏一轮 → 新按 N → 位置螺旋插入 → 自动松手 → 抬升 15 cm → 回固定初始位姿。

保留半径 3 mm、3 圈、0.5 mm 螺旋步长，以及现有速度、加速度、到位、轨迹偏差、反馈时效、超时和暂停检查。松手以最终张手指令成功提交后等待 0.5 秒为依据，不恢复精确手型阻塞。普通启动的左臂回位、已抓持启动及两阶段 bbox 继续保留。

## 清理结果

- 新增 `rail_common`，集中共用坐标与位姿计算、机器人几何、IK、相机、目标示教感知桥和精简日志工具。
- 删除旧左臂预插入状态机、规划回放、独立配置和环境模板；目标示教不再依赖旧运行入口，标定导入统一读取 `receive.yaml`。
- 唯一运动入口为 `insert_spiral.py`；保留检查、只读状态、目标示教、bbox 设置和标定导入工具。删除重复搬运入口、仅估姿、自动搬运和跳过纠偏分支，以及旧实验分析工具。
- 删除已无调用者的笛卡尔轨迹跟随接口及相关旧跟随日志；当前 SDK 位置路径与各段实测检查继续保留。
- 删除约 771 MB 历史输出与旧缓存；有效外参、目标、两阶段 bbox、配置备份、标定原始记录和模型权重保留。
- 运行记录收敛为 `events.jsonl` 和 `result.json`；删除高频反馈日志、逐帧导出、重复规划快照及逐段成功打印。预览与进程通信使用独立临时目录，退出时清理。
- 最终结果保留松手前插入证据、回位结果、最后有效反馈和退出信息；分段执行证据压缩为计数及最后一段反馈。

- 重写插入 README 并修正项目入口链接。训练和策略评估代码不纳入本轮清理。
