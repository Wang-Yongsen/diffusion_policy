# 力控螺旋插入参数填写说明

> 2026-10-25 文献复核更新：下文的具体试调草案是此前未经论文复现与实机验证的估计，暂不作为推荐参数，也不应据此启用插入。用户要求先调研论文；方法依据、适用边界和后续验证见 [启发式力控插入论文调研](./2026-10-25-启发式力控插入论文调研.md)。下文保留为参数语义与历史推导记录。

日期：2026-10-25。对应当前 `lowering.mode: force_spiral`。这是填写与试调指南，未修改实际控制参数、未连接机器人。以下试调数值不是已验证的实机配置。

## 先明确要做什么

“40 项”是底层控制字段的数量，不意味着要做 40 次标定。它们主要来自四类依据：已有机械臂控制配置、相同抓持下的静止噪声、悬空低速跟随表现、工件/夹持允许载荷与受限接触观察。

当前两孔中点已填好；`T_F_S`、`wrench_sign` 仍须确认。实际传感器为坤维，须先核对当前天机反馈的坐标系、力矩原点和比例。现驱动采用 `/10000`；本地明确写出该比例的资料是蓝点安装说明，尚不能作为当前坤维组合的独立单位依据。在这些信息确定之前，报告中的 N/Nm 只能按当前实现解释，不能据此确定实物接触阈值。

推荐顺序：核对传感器定义 → 相同负载静止采样 → 观察悬空低速跟随 → 确定允许载荷与轻触阈值 → 小范围搜索 → 核验实测深度与回退。当前 N 是完整流程，不提供“只测轻触”或“只跑基线”的专用调试阶段；不要把填完参数后直接按 N 当作分阶段试验工具。

## 可以先拟定的慢速运动草案

以下数值用于规划首次小范围试调，使用前需确认实际运动范围和上述前提，当前没有写回 `receive.yaml`：

| 字段 | 草案值 | 含义与使用条件 |
|---|---:|---|
| `approach_speed_m_s` | 0.0005 | 接近速度 0.5 mm/s；无等待时走完 50 mm 理想约需 100 s |
| `insert_speed_m_s` | 0.0002 | 轴向下插速度上限 0.2 mm/s |
| `retract_speed_m_s` | 0.001 | 轴向卸载速度上限 1 mm/s，须验证回退方向与通道 |
| `lateral_speed_m_s` | 0.0005 | 螺旋沿路径的速度 0.5 mm/s |
| `pitch_m` | 0.0005 | 每圈半径增长 0.5 mm |
| `max_radius_m` | 0.001 | 首次只搜索半径 1 mm；需起点至示教目标的横向误差也在此范围内，且整个搜索区域可达 |
| `impedance.velocity_ratio` | 1 | SDK 速度上限 1%；与绝对速度共同生效 |
| `impedance.acceleration_ratio` | 1 | SDK 加速度上限 1% |
| `max_descent_m` | 0.06 | 当前上方高度约 50 mm 时的总下降边界草案；目标仍是示教落座位置，并非强制下降 60 mm |

半径 1 mm 仅用于小范围试验，不保证覆盖 FoundationPose 误差。当前 M 允许数毫米的到位误差，因此可能出现 M 通过、插入因横向走廊不足拒绝启动；应先核对实际偏差和可用空间，不应单纯放大半径以通过检查。

## 40 项逐项填写

### A. 底层阻抗与比例：6 项

当前配置来源：`diffusion_policy/config/tianji_teleop.yaml` 的右臂 profile。已有参数可作对照，但不等于已通过接触插入验证。当前阻抗坐标轴与右臂基座对齐，顺序是 `[X,Y,Z,Rx,Ry,Rz]`；下压为 −Y，搜索平面为 XZ。

| 字段 | 怎么填写 |
|---|---|
| `impedance.stiffness` | 当前参考 `[900,900,900,90,90,90]`。先确认同一导轨/抓姿下能稳定悬空保持；再依据跟随与受力表现调整。Y 为下压柔顺方向，X/Z 为横向方向；降低刚度会增加受力位移，需同时核对参考领先阈值。SDK 平移刚度文档存在量纲文字矛盾，按原生系数处理，不直接用 `900 N/m` 推算接触力。 |
| `impedance.damping` | 当前参考 `[0.27,0.27,0.27,0.27,0.27,0.27]`，为 `[0,1]` 的阻尼比例。结合相同负载下的振荡与响应试调，不用“越大越好”代替验证。 |
| `impedance.nullspace_stiffness` | 当前为 `20`，优先保留已用值，检查冗余关节姿态稳定性。 |
| `impedance.nullspace_damping` | 当前为 `1`，优先保留已用值。 |
| `impedance.velocity_ratio` | 可先拟 `1`；必须为 1–100 的整数，且不能大于接料配置的顶层比例，当前顶层为 `3`。 |
| `impedance.acceleration_ratio` | 可先拟 `1`；整数范围和接料上限约束同上。 |

天机官方说明中也明确：示例刚度/阻尼是参考值，控制器版本变化可能影响参数，应结合实际版本核实：[SDK 文档](https://raw.githubusercontent.com/cynthia-you/TJ_FX_ROBOT_CONTRL_SDK/master/python_doc_contrl.md)。

### B. 静止、姿态及跟随阈值：7 项

在与插入一致的导轨、抓姿、朝向下，采集多段无接触静止数据，例如每段 10 s、重复 3 段；所有采样需要实际静止，不能用增大阈值掩盖明显漂移。

| 字段 | 怎么填写 |
|---|---|
| `baseline_force_std_n` | 取各段各力轴标准差的最大值，初步设为其 2–3 倍，并检查重复采样。它限制的是“标准差”，不是力均值或接触力。 |
| `baseline_torque_std_nm` | 同上，对三个原始力矩轴的标准差设门限。 |
| `baseline_position_tolerance_m` | 略高于多段静止记录的最大位置漂移，且低于能明显破坏悬空/抓持假设的运动量；若两者无间隔，先解决保持问题。 |
| `orientation_tolerance_rad` | 同时满足三项：高于正常保持抖动；允许当前起点与示教目标的姿态差；低于会破坏固定姿态基线或双孔对准的角度。接触中的姿态漂移也使用同一阈值。 |
| `hand_shape_tolerance_rad` | 从右手 20 个关节的保持日志取最大正常关节角变化并留裕度，仍需能发现抓姿变化；力诊断脚本不读取手，不能由其报告计算该值。关节角不变也不能证明导轨没有滑动。 |
| `max_reference_lead_m` | 根据相同负载下的实测跟随误差及受力弹性位移确定。当前实现一旦“已接受参考与实测位置”的误差大于本值的一半，就停止继续推进；因此必须覆盖正常工作误差，同时限制能积累的压入参考。不能只按速度或编码器噪声随意填很小。 |
| `max_tracking_error_m` | 大于 `max_reference_lead_m`，又能及时识别失跟；参考悬空低速跟随日志中的误差峰值和可容许的实际偏离量。 |

例如，反复测得最大力轴标准差为 0.03 N、最大力矩轴标准差为 0.002 Nm，取 3 倍时分别填 0.09 和 0.006。这只是计算示例，需换成实际数据。

姿态阈值尤其不能沿用宽松的视觉门限：两孔中心距 265 mm，在绕两孔中点偏航且中点已对准的理想情况下，每端偏移约为 `132.5 mm × 偏航角(rad)`；1° 对应约 2.31 mm。该关系用于估算角度误差影响，不是确定阈值的完整模型，其他平移/倾斜/配对误差也要占用间隙。

### C. 接触与卸载判据：9 项

以下力均基于悬空基线扣除后的反馈。软限使用滤波值；硬限使用滤波前值。允许载荷取工件、轴、夹持、机器人等实际约束，不能直接用传感器满量程代替。

| 字段 | 怎么填写 |
|---|---|
| `contact_force_n` | 设在正常无接触轴向残差之上，并能识别轻触；可先以轴向残差 5 倍标准差及实测漂移/峰值作为候选下界，再用接触观察确认。方向、比例确定后才能将此下界解释为 N。 |
| `target_force_n` | 选择能维持稳定轻触、又低于允许工作载荷的最小可用目标；须大于接触门限。不依据“插不进去”直接增大。 |
| `max_axial_force_n` | 轴向软限，高于正常目标及正常波动、低于已确认的损伤/松脱风险载荷；超过后请求回退。 |
| `max_lateral_force_n` | 横向力 `sqrt(Fx²+Fz²)` 的软限，结合孔边侧向承载及抓持能力单独确定。 |
| `max_tilt_torque_nm` | 两孔中点处 `sqrt(Tx²+Tz²)` 的软限。理想轴向双点接触时，1 N 的两端受力差对应约 0.1325 Nm，可据允许不均衡载荷建立初步预算，再核对实际姿态/接触。不能直接照抄传感器原点处的力矩峰值。 |
| `hard_force_n` | 未滤波的基线差力三维范数硬停阈值。高于正常工作峰值和软限，低于实际允许载荷并留响应余量；要考虑轴向与横向同时受力。 |
| `hard_torque_nm` | 同时约束传感器原点及孔中点处的未滤波三维力矩范数，两者任一超限即硬停；预算须包含工具力臂，不能仅按孔距填写。 |
| `retract_unload_force_n` | 回到起始高度后判定卸载的残差力范数门限；略高于无接触噪声/漂移包络，并低于仍有实质接触的载荷。 |
| `retract_unload_torque_nm` | 同上，作用于孔中点的残差力矩范数；需要该参考点下的数据，独立诊断脚本的传感器原点统计不足以直接填写。 |

当前校验要求 `contact_force_n < target_force_n < max_axial_force_n < hard_force_n`，以及横向软限小于力硬限、倾斜力矩软限小于力矩硬限。满足不等式只表示配置一致，不表示载荷已验证。

### D. 速度与导纳：4 项

| 字段 | 怎么填写 |
|---|---|
| `approach_speed_m_s` | 草案 0.0005，即 0.5 mm/s；确认未接触阶段的跟随与接触响应。 |
| `insert_speed_m_s` | 草案 0.0002，即 0.2 mm/s；这是下插上限，实际会因力误差和跟随门限更慢。 |
| `retract_speed_m_s` | 草案 0.001，即 1 mm/s；同时限制力偏高时的向上调整和失败回退。 |
| `admittance_m_s_n` | 由 `期望下插速度 / 对应力误差` 估算，再看接触振荡调整。例如希望差 2 N 时达到 0.2 mm/s，则算得 0.0001 m/(s·N)；这里 2 N 是算例，不是推荐目标力或允许载荷。 |

控制公式为 `v = clip(k × (target_force − measured_axial_force), −retract_speed, insert_speed)`。正值向下、负值向上；增大 k 会加快对力误差的响应，也更易受噪声和延迟影响。

### E. 螺旋搜索：3 项

| 字段 | 怎么填写 |
|---|---|
| `pitch_m` | 草案 0.0005 m/圈。结合孔轴有效间隙、剩余角度误差和跟随精度选择，需保证不会因相邻圈相隔过远漏掉可插区域。模型中最紧名义径向间隙约 0.66 mm，但它不包括实物误差、轴根外扩及双孔耦合。 |
| `max_radius_m` | 草案 0.001 m，用于首轮小范围测试；随后根据实际定位误差分布和可用接触区域决定是否调整。它还用于起点至示教目标的横向走廊校验。 |
| `lateral_speed_m_s` | 草案 0.0005 m/s，为沿螺旋曲线的速度；不是角速度，也不是每周期步长。 |

搜索时间估算：`a = pitch/(2π)`，`θ = radius/a`，`L = a/2 × (θ√(1+θ²) + asinh(θ))`，`t = L/lateral_speed`。按上述 0.5 mm 圈距、0.5 mm/s，搜索半径 1 mm 约 12.9 s，2 mm 约 50.6 s；参考跟随被阻塞时更久。半径翻倍时耗时大致变为四倍。

### F. 入孔候选：4 项

| 字段 | 怎么填写 |
|---|---|
| `candidate_depth_m` | 从首次确认接触的实测高度算起；必须大于位置噪声和“顶在孔边也会产生”的弹性下移，否则会把变形当作入孔。观察受限接触数据后选取，不直接用 1.72 mm 孔壁厚度或 14 mm 轴高。 |
| `candidate_force_drop_n` | 从搜索期间轴向力峰值下降多少时冻结横向搜索；需大于正常噪声、滤波延迟及姿态扰动产生的下降。当前代码用历史滤波峰值减当前未滤波轴向力，单帧下降只触发候选，不判成功。 |
| `candidate_confirm_depth_m` | 从进入候选阶段时的高度重新累计的额外下移量；大于候选期间噪声和弹性位移，并小于实际剩余可插行程。两段深度不是同一起点。 |
| `candidate_timeout_s` | 大于 `candidate_confirm_depth_m / 最低正常实测下插速度 + candidate_confirm_s + 裕度`；设置后仍受 phase/total/stall 各超时约束。 |

候选进入下插须同时满足额外实测下移量和候选最短持续时间，并且未先触发停滞或其他超时；代码不要求整个候选期间一直连续下移，一次真实下移后保持到确认时间也可能通过。当前只检测实测法兰进展，没有两孔独立落座传感器，最终仍需人工确认。

### G. 深度、进展与超时：7 项

| 字段 | 怎么填写 |
|---|---|
| `max_descent_m` | 大于从当前上方位置到示教落座目标的实际下降距离，并留可接受余量；当前名义上方高度 0.05 m 时可拟 0.06 m。代码仍限制不能越过示教终点。 |
| `endpoint_tolerance_m` | 根据真实落座精度要求和稳定后的实测位置波动选择；须小于 `candidate_depth_m`。不能直接沿用 M 搬运的数毫米粗定位容差。 |
| `progress_epsilon_m` | 定义多少累计实测下移才算一次进展，亦用于判断上一参考是否已被底层采用/跟上的比较；高于有意义的位姿噪声，低于 `candidate_depth_m`。 |
| `stall_timeout_s` | 高于正常最慢速度走完 `progress_epsilon_m` 的时间并留裕度，且大于 `settle_s`。仅在候选和下插阶段计时，不用于要求搜索阶段持续下移。 |
| `phase_timeout_s` | 接近、搜索、候选、下插共用的单阶段上限；至少覆盖这些阶段中最慢的一段。根据上面的路程/速度计算后留跟随裕度。 |
| `total_timeout_s` | 从基线开始到完成插入的总预算，含基线、接近、搜索、候选、下插及等待，回退另计。不能只按螺旋搜索时间填写。 |
| `retract_timeout_s` | 至少覆盖最大可能回退距离/正常实测回退速度，加到位与卸载等待；回退超时直接停止。 |

按运动草案估算：50 mm/0.5 mm/s = 100 s；保守把完整 50 mm 都按 0.2 mm/s 计算下插预算为 250 s；1 mm 搜索约 12.9 s。可据此拟 `phase_timeout_s: 400`、`total_timeout_s: 600`、`retract_timeout_s: 90` 作预算示例，但必须结合最低实测速度复核，且不能用增大超时掩盖卡滞。这些超时没有写入配置。

## 采样命令与报告字段

在没有其他机器人连接、姿态已经稳定且导轨悬空的条件下，独立采样：

```bash
cd /home/yuchen/project/diffusion_policy
conda activate tianji-rail-diffusion-policy
python workspace/rail_pose_insert/read_insertion_force.py \
  --duration 10 --output /tmp/rail-force-static.json
```

脚本不使能、不改变控制模式、不发送运动指令，也不负责保持机械臂或手。已有 `receive.py` 正在抓料时不能并行启动该诊断进程，也不要为采样直接退出并失去抓持；可使用已有保持阶段日志离线分析。离线重放输入应从需要分析的静止时间段开始，`--duration` 限制的是日志开头的采样时间窗，不会自动寻找静止区间。

```bash
python workspace/rail_pose_insert/read_insertion_force.py \
  --replay /绝对路径/静止片段.jsonl \
  --duration 10 --output /tmp/rail-force-static.json
```

- `raw_sensor_wrench.std`：六轴噪声。诊断使用整段总体标准差；插入控制器使用首基线窗的样本标准差，应留裕度并重复确认。
- `stationarity.max_position_excursion_m` / `max_orientation_excursion_rad`：相对采样起点的最大漂移。它们不是绝对定位精度，也不证明工件相对手没有滑动。
- `base_frame_residual.statistics`：有标定时的基座系残差，力矩参考点仍是传感器原点，没有平移到两孔中点。
- 手型保持与目标跟随门限需要额外读取已有运行日志；这个只读力诊断不提供这两类指标。

## 已有默认项与最终检查

另有 9 个已填的采样/滤波/确认时间参数，不属于上面的 40 项：基线 1 s、至少 30 样本、基线超时 5 s、状态最大龄期 0.1 s、控制间隔上限 0.05 s、滤波时间常数 0.05 s、接触确认 0.1 s、候选最短确认 0.2 s、到位稳定 0.3 s。可以先保留，之后按采样间隔与响应表现复核。

`raw_force_limit_n` 和 `raw_torque_limit_nm` 是额外可选项，约束包含负载和偏置的原始读数，不能复制补偿后接触门限。

填写后执行离线检查：

```bash
python workspace/rail_pose_insert/receive.py check --insertion
```

它检查必填项、数值格式和部分大小关系，不能验证实机载荷或装配安全。首次完整插入之前还需验证反馈方向/单位、悬空稳定、轻触与卸载行为；不要为让检查变成 ready 而填虚构的力限。

实现依据：`workspace/rail_pose_insert/rail_receive/insertion.py`、`rail_receive/hardware.py`、`read_insertion_force.py`；几何依据见同目录《第八版装配台几何核对》。
