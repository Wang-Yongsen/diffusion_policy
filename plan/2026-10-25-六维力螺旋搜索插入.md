# 六维力闭环螺旋搜索插入

> 文献复核状态：现有实现为未完成实机验证的原型，不是某篇论文的完整复现。软件测试不验证双孔接触模型或插入有效性；用户要求先调研论文，证据与待修订部分见 [启发式力控插入论文调研](./2026-10-25-启发式力控插入论文调研.md)。

日期：2026-10-25。范围：右臂接料流程中的 N 键接触插入；不改左臂预插入。软件实现及离线验证，未连接或驱动机器人。

## 已确认的设计

- FoundationPose 粗对齐、M 搬到目标上方并复核后，N 启动一次插入。首版固定实际朝向，只搜索平移。
- 悬空六维力基线 → 沿右基座 −Y 轻触 → X–Z 平面有界螺旋 → 入孔候选确认 → 轴向下插。
- 下降速度来自接触力误差，不按螺旋圈数强制下降。限制参考领先实测量；底层未跟上时不继续积累螺旋相位。
- 深度进展或明显卸载触发停止横向搜索；候选仍需持续实测下移，单次力下降不判成功。
- 到达目标深度并稳定后保持抓握，状态 `awaiting_confirmation`，由人工确认两孔落座，不自动松手。
- 可恢复失败沿 +Y 卸载、回退到起始净空高度，实际卸载后标记 `retracted`。硬故障、失效反馈或操作员暂停直接停止，不自动重试。

## 实现和接口

纯控制器 `rail_receive/insertion.py` 提供配置校验、固定姿态基线、力变换、轨迹及状态转换，不访问设备。`InsertionController.step` 计算下一目标，`accepted` 反馈底层实际接受的参考，`hard_guard` 在提交前再次检查。

`RightHardware.queue_insertion` 只排队；现有单一机械臂线程完成位置模式到笛卡尔阻抗模式的交接，再运行插入。交接从实测 engagement sample 重建参考，第一帧为零位移目标。Driver/CartesianExecutor 的 `configure` 和 `engage` 增加兼容的可选取消事件，覆盖配置、模式等待和首目标阶段。

`insertion_snapshot(after_seq=...)` 返回有界遥测副本。界面线程保存计划、轨迹和结果；控制线程不做文件写入或视觉推理。插入后锁住旧点动、位置运动及手型修改，终态继续保持当前参考和力监测。

默认 `lowering.mode: force_spiral`；旧模式仅通过 `position_steps` 显式选择。缺参只阻止 N，不阻止接料和 M；失败不自动降级。

## 现场参数与边界

`receive.yaml` 尚未确定的物理参数保留必填 `null`：传感器到法兰的标定 `T_F_S`、力符号、插入阻抗、基线稳定阈值、运动/搜索边界、接触力和力矩软硬限、深度与超时等。合成测试参数只存在于测试文件，不作为真机推荐值。

用户已确认目标孔为图示 Ø8.9/Ø8.0、间距 265 mm 两孔。已从当前原始导轨 CAD 的圆柱面 2178/1987 提取两孔孔壁中面中心，并填写 `hole_midpoint_cad_m: [-0.00003262591430678186, 0.2345, -0.0161090627486111]`，单位 m。解析数据与当前 FoundationPose OBJ 的孔口圆环拟合逐轴差异小于 3×10⁻⁹ m；该点只作为力矩参考点，不作为插入深度。详细来源见同目录《第八版装配台几何核对》。

### 传感器安装资料核对（同日补充）

用户确认实际传感器为**坤维智能**，按天机默认位置安装在法兰末端；完整型号尚未提供。查询了完整本地 `TJ_FX_ROBOT_CONTRL_SDK`、机器人手册、装配模型、用户文档目录及[坤维官方手册目录](https://www.kunweitech.com/services/196/p3/)，未找到能绑定当前实物的 `T_F_S` 数值。

- 天机《Marvin系列机器人使用说明书 V2.2》图 4-5、表 4-2 和图 4-6 定义机械臂法兰系与接口，但没有定义外接坤维传感器的测量系。
- SDK `contrlSDK100343/FxRtCSDef.h` 定义右臂 216 为六维力通道；PC 接收代码直接复制反馈，公开代码不足以确认控制器内部是否旋转、移动力矩参考原点或补偿重力。因此必须核对 **216 输出坐标系和力矩参考原点**，不能仅依据本项目的 `sensor axes` 注释下结论。
- 项目 `sim_right_tool_sensor` 的单位变换来自“模拟六维力传感器.step”，是仿真几何装配值，没有坤维型号或测量系标定依据。40 mm 的模拟外形长度也不能代替测量原点偏移。
- 本地找到的《天机Marvin系列_末端蓝点六维力安装说明20260423.pptx》属于另一品牌，不用于确定当前坤维传感器的安装关系。其数据缩放说明也不足以独立核验当前坤维/控制器组合；现有缩放需与该组合的官方定义或已知载荷读数核对。

`T_F_S` 和 `wrench_sign` 继续留空。要确定矩阵，需要完整型号对应的轴向/测量原点图、实际安装朝向，以及控制器输出坐标定义；直接安装并不保证测量原点与机械臂法兰原点重合。补入两孔中点后，离线 `receive.py check --insertion` 正常解析配置，剩余 42 个必填叶子参数未确定，N 仍保持禁止启动；本次未连接机器人。

基线扣除只适用于悬空、固定朝向及不变抓持。力和力矩转到右基座，并考虑传感器原点到两孔中点的力臂；不能仅旋转力矩。当前工具动力学不等于已包含导轨或已补偿原始六维信号。

本版不补偿接触中的偏航/倾斜，不保证平移螺旋能解决双孔角度或孔距误差。目标深度仍由经验证的示教目标定义；轴高、CAD 孔壁厚度不能直接代替真实装配深度。无场景碰撞检测，软件力限及 watchdog 不能等同硬件安全回路。

`read_insertion_force.py` 提供只读力诊断及 JSONL 离线重放；不使能动作、不推导接触载荷、不自动生成标定。`receive.py check --insertion` 在不连接设备的情况下报告缺项。

## 验证

实施前原下放、位置模式、上方搬运基线 45 项通过。新增验证覆盖：

- 基线稳定性、序列去重/新鲜度、力符号与测量原点变换、滤波前硬限。
- 螺旋范围/速度、受限跟随不累积目标、入孔候选冻结、正常深度保持、软失败卸载回退及硬故障。
- 单一控制线程、实测种子、新 profile、模式确认及取消、提交前突发过载、终态不恢复旧运动。
- N 缺参拒绝、不降级、重复请求锁存、日志去重/缺口、暂停后保留执行证据，以及完整模拟接触—搜索—插入—保持。
- 只读诊断不调用运动接口，原接料/搬运/逐段下放回归。

最终验证结果：

- 控制器、硬件交接、N 路由、只读诊断、原下放/搬运/接料/入口/显示，共 183 项回归测试通过；最后补充遥测采样对应关系测试并收紧阻抗字段复制后，相关 51 项测试再次通过。
- `verify_bundle.py --source-only` 校验 1,451 个文件通过；两个驱动改动文件及嵌套 manifest 摘要已同步。
- `git diff --check` 与改动 Python 模块编译检查通过。
- `receive.py check --insertion` 按预期返回未就绪，原因仅为必填现场参数未填写；未自动启用位置下放。
- 对既有 `m_key_diagnosis_20261025/events.jsonl` 离线诊断获得 59 个有效样本，明确报告旧日志缺右臂源序列、标定/静止阈值缺失等限制，没有推断真机力限。

复核修正了三处时序/记录问题：控制周期在取反馈后采样当前时间；硬停保留触发故障的真实力和位姿；提交与暂停竞态保留“接受结果未知”，不错误宣称未执行。原始力、未滤波补偿力使用同一最新反馈，滤波值单独标注时间戳。终态继续更新力遥测及监测持续软超限。

真实插入力、搜索范围、成功率与落座准确性未作真机验证。
