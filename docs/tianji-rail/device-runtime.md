# 天机、无极手与相机运行约定

运行所需适配代码、天机 SDK 和运动学模型均在本项目。[快照来源](../../third_party/README.md)与[厂家清单](../../third_party/bimanual_teleop/vendor/tianji/manifest.json)用于版本追溯，不需要另一项目目录。

| 文件 | 现场核对内容 |
| --- | --- |
| [天机配置](../../diffusion_policy/config/tianji_teleop.yaml) | 控制器 IP、双臂控制参数、关节及伺服限制 |
| [无极配置](../../diffusion_policy/config/wuji_teleop.yaml) | 双手地址、SDK 用户名、控制／反馈频率、MIT 参数 |
| [相机配置](../../diffusion_policy/config/recording.yaml) | 三路 D436 序列号及顺序：`camera_0` 主视角、`camera_1` 机器人左臂、`camera_2` 机器人右臂；策略只启用 RGB |
| [部署配置](../../diffusion_policy/config/tianji_rail_real_eval.yaml) | 相对设备配置路径、观测时效、工作空间、速度及试验设置；末端版与关节版共用，单次修改用入口的 `--set` |

当前 IP、用户名和相机序列号来自原设备配置，不表示适用于另一台机器。相机顺序与旋转须和训练数据的采集约定一致：左臂相机倒装，`camera_1` 的 RGB 在读取后、缩放前旋转 180°，并在相机元数据中记为 `image_rotation_deg`；其余两路不旋转。部署配置中的相对文件路径按本项目根目录解析；默认设备配置、SDK 原生库及模型按包位置解析，移动项目后重新创建环境即可。主机须为 Linux x86_64，并具有环境所要求的 GPU 驱动及设备连接条件。

天机官方控制库版本为 `100343014`；封装、`libMarvinSDK.so`、`libKine.so`、M6 4.0 模型及 Apache-2.0 许可证一起随项目保存。默认 FK 模型摘要为 `ce20b1a80974c3ed58cdac4973152625096c8ad93a779e5fd4108c26ce19bd52`，部署入口将其与配置核对。名义模型不包含设备个体标定。离线 FK 仅加载运动学库，不启动控制 SDK 或连接机器人。

无极 SDK 固定为 `wuji-sdk==2026.10.12`，环境依赖与适配层版本检查须一起更新。本机左右 Hand2 使用固件 `2.12.0`；从 `2.6.0` 升级后，SDK 端口由 `7447` 改为 `50001`，双手地址已在无极配置中同步。固件从 `2.10.0` 起默认启用内置关节前馈补偿；适配层发送的外部前馈电流为零，不代表关闭设备内置补偿。固件升级使用 [Wuji CLI](https://docs.wuji.tech/docs/wuji-cli/firmware-upgrade) 按序列号选择匹配硬件的官方包，升级后须重新读取版本、关节诊断和控制参数，再进行现场动作验收。

## 单位与接口回执

公共接口使用米、弧度和秒。天机 SDK 的关节角使用度，FK 平移使用毫米，由适配层转换。官方 Jacobian 已使用 SI 单位，不能再次将其平移行除以 1000；形状为 6×7。适配层修正官方封装的整型与浮点精度处理，使用原始状态精度，厂家 SDK 文件未改。

`SDK_SUBMITTED` 和成功 `Submission` 表示 SDK 接受命令，不是 UDP 发包确认或物理到位。`received_monotonic_ns` 是主机取出 SDK 状态的时间，`packet_index` 是本地序号，不是原始 UDP 序号；重复缓存不刷新状态有效期，序号跳变不能直接推断网络丢包。相机 GLOBAL_TIME 映射到主机单调时间，但三路曝光仍需单独核对。

## 控制与停止

双臂定时提交共用 SDK 互斥保护，等待空闲槽受有效期及取消条件约束。策略采用约束笛卡尔执行器；手部保持使用各自线程，单设备故障不会依赖 GPU 推理返回后才处理。已被 SDK 接受的命令不能由厂家接口撤回，因此必须记录停止请求与实际反馈。

暂停清空未来策略目标，双臂以实测关节为参考请求保持，健康手持续提交最后已接受的目标。退出仅对本程序曾控制的臂执行 servo-off 并检查新鲜停止反馈；只读连接不执行该操作。通信失败时不能把退出请求当作已经确认停止。退出禁用双手，操作员应先处理抓持物。

`--check-only` 无设备连接；默认影子模式读相机和反馈，不配置运动参数或使能。`--motion` 仍要求实测工作空间及每次手动开始。时效、控制周期、停止和短时闭环需现场验收，模型离线重载、库导入或 FK 通过均不能替代。操作与记录见[快速使用](README.md)。

本说明提取了源项目与本流程相关的 SDK、单位和生命周期约定，保留本地代码与资源定位，不引用源项目的开发文档。
