## 接受的复核更正

- 把画面平均亮度调到 111 不是已验证的修复。第 1 次决策的 `camera_1` 上半帧两边接近，下半帧真实画面更暗，不是均匀变暗。
- `camera_1` 是最先要查的通道，不是已经证实的唯一原因。`camera_0`、`camera_2` 也有厘米级效应，单通道结果会互相抵消。
- 同步推理期间的运动不能解释最早偏差。闭环第 0 次从锚点到返回，左臂实测只动了约 0.57 mm，模型目标已经相对回放向下偏。
- 两段 `trace_valid=false` 不能忽略。状态日志在正式运动前就被 `tianji.source_gap` 写满。前段决策、命令和反馈仍可用来看输入和输出。闭环后 16 次决策的图像不在缓冲里，不能用来审计最后一次超速中止。
- 回放多了慢速接近，第 0 块还在按 s 之前算过；闭环没有这段。两段不是完全相同的物理起步过程。
