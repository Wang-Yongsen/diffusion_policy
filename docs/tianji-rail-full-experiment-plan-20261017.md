## 1. 目标与最新事实

用户已经测试：逐时刻输入训练集观测，真机执行较好；逐时刻输入验证集观测也较好、稍差于训练集；切换到真实机器人观测后，左臂只能向外少量移动，之后局部抖动。

本次目标是区分并定位：

1. 本机代码、权重、推理设置或输入转换不一致。
2. 实时图像内容与示教分布不同。
3. 实时 EEF/手状态的值、坐标、历史或起始条件不同。
4. 图像与状态的时间对齐、队列、推理/执行节奏不同。
5. 真实机械臂的跟踪误差使后续输入偏离示教。
6. 排除上述实现问题后，模型对采集条件或离轨状态的泛化不足。

交付必须有可复跑输入、代码、指标和证据结论，不以“可能训练不好”“需要更多数据”代替分析。已知是目标输出停滞，尚未证明唯一诱因。训练/验证回放好降低了“只记住训练轨迹”的优先级，但它们都移除了真实反馈，因此不等于通过闭环泛化测试。

执行范围：先做离线推理和只读观测采集；运动验证放在最后，沿用用户已有人工开始/停止流程。混合图像/状态、改变时间顺序、人工扰动的输入只做离线诊断。计划本身不授权自动启动机器人运动、改变设备配置或开启长时间训练。

## 6. E3：图像与状态2×2配对实验

E=示教、R=真实；第一个字母是三路图像，第二个是EEF+手状态：

| 条件 | 图像 | 状态 |
|---|---|---|
| EE | 示教 | 示教 |
| RE | 真实 | 示教 |
| ER | 示教 | 真实 |
| RR | 真实 | 真实 |

参考在查看模型输出前选定：先匹配抓取阶段/物体关系，再比较EEF姿态和手形。真实第5秒不等于示教第5秒。每个真实样本先选3个参考，尽量覆盖训练/验证两个来源；一组按任务阶段、一组按姿态近邻，并报告距离。参考稀疏且无近邻时，明确“参考支持不足”，不按最好输出挑参考。

第一轮上限3个真实样本×3个参考×4条件×seed42=36次。再选最有区分力的2个配对，使用 `[42,43,44,45,46]`；已跑seed可复用，避免无边界扩大。

四组从原始数组组合后统一进入实际部署preprocess；同模型、EMA、eval、DDIM8、同设备、同初始噪声。CPU/CUDA相同数值seed不保证相同随机噪声。记录所有8步52D动作，不只报告一个Z值。

必须同时给出：相对每组自身最新EEF的位移，以及相对同一真实当前EEF的位移。否则换状态造成的绝对坐标平移会被误当作纠偏或推进。

配对效应：图片效应 `RR−ER`、`RE−EE`；状态效应 `RR−RE`、`ER−EE`；位置交互 `RR−ER−RE+EE`。旋转用SO(3)距离而非rotvec分量相减。效应与同输入不同seed波动、不同参考差异一起解释；四组是敏感性干预，不是四组物理可执行任务。

## 7. E4–E7：把差异定位到字段和时间

### E4 图像侧

仅在E3有稳定图片效应时展开：

1. 固定真实状态，三路图像逐一替换，再做反向检查；其余相机保持不变。若有交互，再测试必要的双相机组合。
2. 对有影响的相机并排展示两帧原始RGB与参考：实际视角/机位、腕相机随机器人姿态变化、主相机朝向、导轨/孔口位置、手和物体遮挡、背景、曝光/白平衡、运动模糊。
3. 核对实际像素而不只核对serial：颜色顺序、唯一一次180°旋转、左右腕顺序、分辨率、裁剪、缩放、自动曝光预热。包内参考不得二次定向。
4. 只对有明确依据的因素做离线单变量复原；图像光度变化与几何变化分开。不要枚举旋转/通道排列后以输出最好就宣布正确。
5. 黑图/遮挡仅可测依赖，不能当真实场景的准确率测试或证明某相机无用。

### E5 状态侧

即使E3图片效应更大，也要报告真实起点相对参考的差异；深入拆分仅在状态效应成立时进行：

1. 依次替换左EEF、右EEF、左手、右手，再把主要EEF拆成XYZ和姿态、最新帧和两帧历史。
2. 用同一包实际关节按本机实际FK重算EEF；核对原生基座/法兰定义、左右顺序、米/弧度、关节顺序、rotvec定义与分支。比较必须是同一采样时刻。
3. 区分实测关节、控制器目标、内部积分q和请求目标。训练观测来自实测关节FK，不能拿命令目标冒充真实状态输入。
4. 报告初始及失效样本到示教近邻的XYZ、SO(3)、手关节距离；同阶段和全数据近邻分别统计。训练/验证的留出单位是source episode，不随机拆相邻帧制造独立性。
5. 用checkpoint现有统计检查真实输入的归一化值、越界字段及范围；越界是证据，不自动裁剪到[-1,1]。不在部署端重新fit normalizer。
6. 姿态有SO(3)接近而rotvec数值突变时，检查表示分支及训练覆盖；不随意改成Euler输入。

### E6 时间、历史与队列

先审计原始记录；仅对异常项做同一历史上的离线重构：

- 两帧是否按旧→新排列、间隔是否约33.33 ms；相机各自选帧时间、重复帧、三相机跨度、状态插值区间。
- 时间戳表示设备帧时间还是主机取出时间；是否有共同单调时钟；状态/图像是否缓存旧值、复用了可变内存、左右反馈sequence停止更新。
- 观测anchor→进入模型→返回预测→首目标下发的时间；新观测是否仍描述上块执行中状态；hold是否真正静止，以实测差分判断。
- 从已保存候选历史，比较生产选帧与符合训练契约的因果选帧/插值。可以测重复最新帧的影响，不把倒序/未来帧版本当可部署修复。
- 分开测试图像对齐、状态对齐和历史长度，不同时改变三者。严格不使用决策时尚未到达的数据来证明修复有效。

### E7 推理运行环境与随机性

- 同一真实快照、同一模型：直接调用与实际子进程调用，核对原始/准备后输入、normalizer、eval、EMA、dtype、DDIM配置。
- 精确复现现场输出时恢复采样前RNG或初始噪声；session.seed=42不等于每次预测重设seed42，预热和之前推理会消耗随机数。
- CPU配对先做；实际CUDA路径用同设备同噪声比较。跨CPU/GPU比较优先传相同初始噪声，不能把相同seed当相同噪声。
- 关键3份输入用5个seed记录全部8步均值/范围，分开量化随机抖动和输入变化。
- 只在前述结果仍指向采样问题时，对2份输入临时测试DDIM8/32/50和main/EMA；保持权重不变，分别记录效果与耗时。已有示教抽查显示增加去噪步数只小幅改善，不默认这是修复。

## 8. E8–E9：首次偏离、真实跟踪和同步节奏

这部分以新的完整记录为依据；不能从旧events补造实测轨迹。

### E8 找到最早异常

把一次正常人工启动测试的前1秒逐块展开，之后延伸到首次失去推进时刻。至少画出同时间轴上的：

1. 模型输入的最新EEF、两帧差分与图像/状态年龄。
2. 原始预测与通过校验后的计划目标。
3. 伺服内部应用位姿/关节，以及真实关节FK。
4. 推理时间、sync hold、目标下发时间、progress/limited、关节余量和所有fault。

`tracking_status.position_error_m` 是请求目标相对内部命令FK的误差，不是实测误差；`submit accepted`不代表到位。分别计算请求→内部、内部→实测、请求→实测，寻找第一个持续偏离发生在哪一层。

- 初始第一块就明显偏离：优先E3–E5的实际输入与起始条件。
- 开始合理、跟踪先落后，随后预测变差：支持真实动态/闭环偏差路径。
- 实测能跟随，但预测目标开始回拉：支持策略/观测内容路径。
- 只在最后手指超速中止：把终止事件和此前左臂失败分开解释。

### E9 节奏和跟踪的条件对照

只有E8显示时序/跟踪相关，才改这一层：

- 先用相同请求目标离线比较连续30 Hz与记录到的sync起停，核对已有结论是否适用于本机版本。
- 如需验证停稳问题，提出显式的到位/速度测量判据和有限等待超时，记录实际是否满足；不要把“保持末目标”当已停稳。
- async仅在实测推理延迟与动作覆盖能够支持时作为独立条件；不能机械切换造成覆盖耗尽。保持30 Hz观测/动作契约，不直接用15/10 Hz去执行这份模型。
- 所有物理对照沿用完整真实观测和现有人工开始/停止流程。先每条件1次完整记录；若有改善，再在相同起始条件至少3次检查一致性。
- 不把混合输入下发，不通过放宽阈值掩盖输入或跟踪错误。不同时改速度、动作块长度、同步模式和模型。

## 9. E10–E11：只有实现问题排除后，才展开泛化和训练

### E10 泛化/恢复覆盖

1. 核实用户所谓验证来源确实未参与训练；已有10参考只用于诊断，不代表完整评估。
2. 在独立完整验证来源上报告抓轨前段和全程动作误差，避免仅用52D噪声loss代表任务能力；数据按完整source episode划分。
3. 若真实差异主要在图像，离线分别测几何/外观因素；若在起点/姿态，沿真实已观测到的偏差方向做小幅局部敏感性测试，幅度来自实测而非任意大扰动。
4. 人工状态扰动但图像不变属于不一致输入，只能说明敏感性，不能代替真实恢复任务。
5. 真正的场景外/离轨测试需要物理一致的图像与状态：分别改变一个已定位因素，记录首块动作方向、是否回到正确推进、到达时间和成功/中止。现场操作员按设备条件设置初始状态，不由AI自动创造新运动姿态。

理论上，示教回放好而策略自身诱导的观测下失败，与模仿学习的分布偏移相容；这不是仅凭现象就能确定的原因。[DAgger原论文](https://proceedings.mlr.press/v15/ross11a.html)

### E11 最小修复与训练对照

根据证据选择一条，不把所有改动一起上：

| 已确认机制 | 优先修复/对照 | 验证方式 |
|---|---|---|
| 输入转换/字段/队列错误 | 修复第一个错误边界 | 相同保存输入逐元素回归，再用真实输入验证 |
| 图像采集条件发生可恢复偏差 | 恢复正确机位/定向/采集参数 | 相同场景前后采样与配对预测，不改模型 |
| 初始状态与采集条件不匹配 | 对齐现场起点；核查读数与FK | 记录实际起点与首块动作，不直接更改模型表示 |
| 时序/跟踪失配 | 单独修复对齐、反馈或调度 | 同记录离线回放＋完整真实闭环实测 |
| 物理一致条件下仍缺乏离轨恢复 | 收集已出现失败附近的纠偏/恢复示教 | 固定原数据，单独增加恢复数据，按场景/来源留出 |
| 主要是外观/视角覆盖不足 | 有针对性增加覆盖或符合现场差异的增强 | 变化类型分组留出，检查原条件能力是否退化 |
| 主要是动作采样误差/不连续 | 受控比较训练进度、采样设置或动作目标 | 保持数据/预算/评估集固定，评价推进与粗糙度 |

新训练另立运行目录和计算预算，不影响当前训练。不默认执行长训练；先交付已定位机制及最小训练对照。执行时匹配训练步数、source split、学习率计划、模型选择规则；不能把“训练更久”和“方法有效”混为一谈。先固定一个seed筛选，方向稳定后再多seed确认。

不预设删除本体状态、切换绝对/增量动作或修改网络/损失就能解决。确需改表示时，必须同步验证数据、normalizer、推理切片和部署单位契约，作为独立实验。

## 10. 统一指标、判定标准与停止条件

每份快照/实验都保留全部8步52D动作，至少输出：

- 左/右臂绝对XYZ；相对自身输入状态、相对固定真实状态的XYZ位移；SO(3)姿态距离。
- 相邻目标位移中位/p95、Z增量反号、块间目标跳变；只有真实连续序列才报告累计回拉和推进率。
- 有示教真值的EE才计算对应 `expert_action[1:9]` 的动作误差；其他混合条件没有天然真值，不虚构准确率。
- 时间年龄、两帧间隔、重复比例、相机跨度、推理耗时/hold、控制实际频率、请求/内部/实测跟踪误差。
- 多seed和多参考的效应范围；报告反例，不只展示最好窗口。

数值差异需超过同输入随机波动并在多个参考/seed下保持方向，才认为值得归因。10 mm位置、3°姿态可作为本次查看的提示量级，不是普适根因阈值或设备控制阈值。

一个机制的可信证据链应包含：可重复异常→单变量干预稳定改变异常→独立字段/时间证据说明改变了什么→最小修复在原保存输入上通过→条件允许时真实闭环复核。2×2混合输入或模型敏感性单独不能完成这条证据链。

停止/转向规则：

1. E1发现确定实现差异，先修复并回归，再继续其他原因分析。
2. E2未采到与失败相关输入，报告实际缺失，不能靠随机扩增实验宣称找到历史根因。
3. E3效应被参考/seed反转，先改善匹配或补少量样本，不立刻重训。
4. 已找到可重复、最小修复有效的原因后，其他未触发分支标为“不需执行及原因”。
5. 本机设备或训练数据不可用时，继续能做的离线实验，记录哪些结论因此不能成立；不反复要求用户决定实现细节。
